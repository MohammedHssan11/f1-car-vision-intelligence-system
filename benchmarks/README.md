# Phase 4 Benchmarks

This folder contains the benchmark manifest, runner, and generated results for model-quality tracking.

## Run

```powershell
py -3.11 benchmarks\run_benchmarks.py
```

Quick image-only iteration:

```powershell
py -3.11 benchmarks\run_benchmarks.py --skip-video
```

## Files

| File | Purpose |
| ---- | ------- |
| `manifest.json` | References existing project samples without copying data. |
| `run_benchmarks.py` | Runs image and video samples through the current runtime model paths. |
| `benchmark_results.md` | Human-readable benchmark report generated by the runner. |
| `results/benchmark_results.json` | Machine-readable benchmark output generated by the runner. |
| `results/images/` | Annotated benchmark image outputs. |

## Evidence Boundary

Only team labels are available in the current image samples. Car boxes, damage labels, video tracks, collisions, and overtakes do not have ground truth labels in this manifest, so those values are recorded as measured observations rather than scored accuracy.
